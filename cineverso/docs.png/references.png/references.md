# Referências Visuais e Decisões de Design

## Referências Consultadas

1. **Letterboxd (Perfil/Lista):**
   - **Elemento Utilizado:** Disposição dos cartões em grade (Grid System) com capas em destaque visual.
   - **Onde foi utilizado:** Páginas de catálogo (`/movies`) e lista pessoal (`/my-list`).
   - **Justificativa:** Proporciona uma navegação limpa e focada no aspecto visual das capas dos filmes, ideal para rápida identificação pelo usuário.

2. **Netflix (Navegação/Hero Banner):**
   - **Elemento Utilizado:** Destaque superior para conteúdos populares.
   - **Onde foi utilizado:** Página inicial (`/`).
   - **Justificativa:** Capta imediatamente a atenção do usuário e incentiva a descoberta de novos títulos em alta.

3. **Spotify (Adicionar à Minha Lista/Biblioteca):**
   - **Elemento Utilizado:** Botão rápido de atalho para adicionar/remover de listas pessoais.
   - **Onde foi utilizado:** `MovieCard` e página de detalhes do filme (`MovieDetails`).
   - **Justificativa:** Interação intuitiva com feedback visual imediato ao gerenciar conteúdos salvos.
